# Submission Checklist — CSE 310, W02 Data Analysis

This bundle contains a working project and reference documents. **It is not a fully submitted assignment.**

1. Read and understand `analyze_sales.py`, make your own changes or improvements, and verify that your work follows your course's rules on original code and assistance.
2. Run `python -m pip install -r requirements.txt` from the project folder.
3. Run `python download_dataset.py` to obtain all 16,598 records. If that fails, download `vgsales.csv` manually from the dataset source in README.md into `data/`.
4. Run `python analyze_sales.py` (no `--sample` flag) and review the results. Change the sample-only statements in README.md to the actual full-dataset results if desired.
5. Run `python -m unittest discover -s tests -v` and confirm tests pass.
6. Create a **public** GitHub repository named `video-game-sales-analyzer` and publish code and README.md. This bundle has **not** been published to your GitHub account.
7. Record your **own** 4–5 minute video including your **face, audio, live demonstration, and code walkthrough**. Verify the recorded audio by playing the video back.
8. Upload the video to YouTube or university video storage. Make sure the URL is accessible to your grader.
9. Post your video URL in the Microsoft Teams **Data Analysis** channel.
10. Complete the required **Learning Strategies** discussion with your real experience, using the draft only as a starting point.
11. Fill in `TIME_LOG.csv` with the **actual** dates, work descriptions, and hours you personally spent. The rubric expects 20+ hours; do not copy the planned hours as though they were completed.
12. Fill out the official **Module Submit Form** online and **download its generated Word document**. Insert your real public GitHub URL, video URL, time log, and answers. Submit that Word document in Canvas.

**Note:** The Word file you uploaded with your request is titled W01 Hello World Module. It is a previous assignment, not the official W02 Module Submit Form.
